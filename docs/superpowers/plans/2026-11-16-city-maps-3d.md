# 나라·도시 맵 + 캐주얼 3D 전환 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 테마 코스 5개와 2D 캔버스 렌더러를, 나라(3) → 도시(12) 선택과 실제 명소가 나오는 three.js 캐주얼 3D 세계로 교체한다.

**Architecture:** 주행 로직(`game.js`)은 "경로 따라 간 거리 s + 좌우 위치 x"만 다루고 그대로 둔다. 새 순수 모듈(`path.js`, `cities.js`, `layout.js`)이 굽은 길의 3D 중심선, 도시 데이터, 배치를 계산한다. `render.js`는 같은 `Renderer.render(scene)` 모양을 유지한 채 three.js로 바뀌고, 그 아래 `three/` 폴더가 소품·명소·움직임·캐릭터를 만든다.

**Tech Stack:** Node 24, 브라우저 ES 모듈(빌드 도구 없음), three.js 0.187 (npm, 서버가 로컬 제공), `ws`, 테스트는 `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-16-city-maps-3d-design.md` — 도시별 명소·배경·움직임 표는 spec이 원본. 실행자는 둘 다 읽는다.

## Global Constraints

- 인터넷 없이 동작. three.js는 `/vendor/three/`로 로컬 제공. CDN 금지 (기존 Google Fonts 링크는 그대로 둠).
- 빌드 도구 추가 금지. 새 의존성은 `three` 하나.
- 목표 1080p 60fps, 최저 30fps. 실시간 그림자 맵 금지 → 바닥 둥근 그림자. 재질은 `MeshLambertMaterial`(flatShading). 반복 소품은 `InstancedMesh`.
- 픽셀 수 제한 유지: `k = Math.min(devicePixelRatio || 1, 2, 1920 / cssWidth)`.
- 도시 진입(장면 조립) 3초 이내.
- 밤 배경·어두운 색·빠른 깜빡임 금지. 색 변화 주기는 2초 이상.
- 실제 상표·로고·글자 금지 (도톤보리 간판, 타임스스퀘어 전광판은 색 판만).
- 후방 쿼터뷰 유지: 카메라는 플레이어 뒤 위.
- 도시 id는 `^[a-z]{1,12}$` (서버 검증 정규식 그대로).
- UI 글자는 한국어, 폰트 Jua 유지.
- `Introduce.md`, `CLAUDE.md`는 수정·커밋하지 않는다 (`.gitignore`에 있음).
- 세계 좌표: 1단위 = 트랙 세그먼트 1칸. y가 위. 길 반폭 `RW = 3.6`. 캐릭터 키 약 1.6.

**Interfaces:**
- Produces (`path.js`):
  - `export const RW = 3.6`
  - `buildPath(segs: {curve:number}[]) → { n, x: Float32Array(n+1), z: Float32Array(n+1), yaw: Float32Array(n+1) }` — 점 i는 세그먼트 i의 시작. `yaw[0]=0`, 진행 방향 +z. `yaw[i+1] = yaw[i] + segs[i].curve * TURN` (`TURN = 1.5`), `x[i+1] = x[i] + sin(yaw[i])`, `z[i+1] = z[i] + cos(yaw[i])`.
  - `sample(path, s: number, lateral = 0, out = {}) → { x, z, yaw }` — s는 실수(범위 밖은 끝값으로 고정), 점 사이 선형 보간. lateral 양수 = 진행 방향 오른쪽.
- Produces (브라우저): `import * as THREE from 'three'`, `import … from 'three/addons/…'` 가 `/vendor/three/build/three.module.js`, `/vendor/three/examples/jsm/…`로 풀림.

- Produces (`cities.js`):
  - `COUNTRIES = [{ id:'kr', name:'한국', flag:'🇰🇷' }, { id:'jp', name:'일본', flag:'🇯🇵' }, { id:'us', name:'미국', flag:'🇺🇸' }]`
  - `CITIES: City[]` — id 순서: `seoul, busan, suwon, ulsan, gyeongju, tokyo, kyoto, osaka, sapporo, shizuoka, newyork, sanfrancisco`. 한국어 이름은 spec 표대로.
  - `cityById(id) → City` (없으면 `seoul`), `citiesOf(countryId) → City[]`
  - `City = { id, country, name, tune: 0..4, sky: [top, bottom], fog: '#rrggbb', ground: [a, b], road: [a, b], edge: [a, b], lanes: 0|1|2|3, sides: { left: 'land'|'water'|'snow'|'sand', right: 같은 값 }, landmarks: Landmark[4], backdrop: [{ id, bearing: 도(0=진행 방향), dist }], roadside: [{ n: string[], p, min, max, side?: -1|1 }], ambient: [{ type, …옵션 }], hero: landmark id }`
  - `Landmark = { id, name, at: 0..1, side: -1|1|0, offset, h, through: boolean, span, features: string[3..5], model?: string }` — `at`은 `0.2, 0.4, 0.6, 0.85` 순. `side: 0`이면 통과형(`through: true`), `span`은 길 따라 차지하는 길이(통과형 문 6, 도리이 터널 40, 다리 80; 옆에 서는 명소는 0). `h`는 화면 목표 높이(12~45). `features`는 spec "닮음 기준"의 꼭 맞아야 하는 특징.
  - `spanOf(def, lengthUnits) → number` — 통과형이면 `Math.max(6, Math.min(def.span, 0.14 * lengthUnits))`, 아니면 0. 짧은 코스에서 다리·터널 길이를 줄인다. 트랙 생성·배치·명소 조립이 모두 이 값을 쓴다.
  - 명소 id 규칙: `<도시>_<이름>` 소문자·밑줄 (예: `seoul_gwanghwamun`). 먼 배경 id: `bg_<이름>` (예: `bg_fuji`).
  - `ambient.type` 값: `'wind' | 'birds' | 'butterflies' | 'crowd' | 'mover' | 'particles' | 'floater'`. `mover`는 `{ kind, lateral, speed, period }`, `particles`는 `{ kind: 'petal'|'snow'|'leaf' }`, `birds`는 `{ kind: 'pigeon'|'gull'|'magpie'|'kite' }`, `floater`는 `{ kind: 'balloon'|'whale'|'ferriswheel'|… }`. 모든 도시에 `wind`, `crowd`, 그리고 `birds` 또는 `butterflies`가 있어야 한다.
- Produces (`game.js`):
  - `buildTrack(city, lengthM, upm, seed) → { segs: {curve, line}[], start, finish }` — `sprites` 필드 제거.
  - `Race` 옵션 `course` → `city`로 이름 변경, `race.city`. 새 이벤트 `on('landmark', name)`: 내 거리가 `at * lengthM`을 넘을 때 한 번씩.
  - `scene()` 반환에서 `course` → `city`, `skyOff` 제거. `items`, `camPos`, `camX`, `t`, `speed01` 유지. `track` 유지.
